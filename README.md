# Nostra Casa Builder

Monte o site completo da Nostra Casa Pizzaria e Lanches com base nos arquivos enviados e garanta que todas as funções funcionem. No painel administrativo tem que ter como editar os produtos já criados e os ingredientes, criar novos ingredientes para o produto e também remover quando quiser os ingredientes e os produtos, e também colocar as imagens dos produtos e todas as fotos que o site tiver ter como alterar e salvar, garantindo que tudo esteja funcionando como tem que ser.
